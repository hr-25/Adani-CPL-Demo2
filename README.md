# Adani Cement CPL 2026 - Auction Engine Demo

Interactive, broadcast-grade Corporate Premier League Auction Engine designed for Adani Cement CPL 2026.

## 🏏 Features

- **Live Auction Room**: Real-time bidding interface with bidding increments, timer countdown, and live bidding status.
- **Admin Console**: Complete control over auction flow, bidding control, player assignment, and budget monitoring.
- **Projector Display**: Fullscreen, broadcast-ready display view optimized for presentation projectors and large screens.
- **Team Manager**: Track team rosters, remaining purse balance, player count, and category breakdown.
- **Player Pool**: Searchable and filterable registry of all players with auction status (Upcoming, Sold, Unsold).
- **Sound & Visual FX**: Interactive gavel sounds, countdown alerts, and victory confetti celebration effects.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Celebration FX**: Canvas Confetti

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
npm install
```

### Development Server

Run the development server locally:

```bash
npm run dev
```

### Production Build

Verify and build the project for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## ☁️ Deployment on Vercel

1. Push this repository to GitHub.
2. Sign in to [Vercel](https://vercel.com) with your GitHub account.
3. Click **"Add New..."** -> **"Project"**.
4. Import `Adani-CPL-Demo`.
5. Framework Preset will automatically detect **Vite**.
6. Build command: `npm run build` | Output directory: `dist`.
7. Click **Deploy**.
